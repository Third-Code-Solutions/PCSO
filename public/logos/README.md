# Logo assets

| File                | Purpose                                                                                                                                                                                                                            |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pcso.svg`          | In-app chrome (sidebar, top nav, auth hero) — vector reconstruction.                                                                                                                                                               |
| `pcso-official.png` | **You need to drop this in manually.** The high-fidelity raster seal for PDF output (payroll register, COE, SR, NOSI, NOSA, CSC Form 9, appointment, CT). Save the official PCSO seal as `pcso-official.png` at 960x960 or larger. |

If `pcso-official.png` is absent, PDF generators fall back to `pcso.svg` (which still renders correctly but is a simplified reconstruction).
